# Ntrungz Remote Control — Android Client (apps/android)

Ứng dụng di động Android chính (Client Layer) cho phép điều khiển Windows PC từ xa:
- Xây dựng bằng React + TypeScript + Capacitor.
- Nhận luồng video WebRTC 30 FPS (< 150ms).
- Chuột cảm ứng ảo (Trackpad, Left/Right click, Scroll wheel, Pinch to zoom).
- Bàn phím ảo đầy đủ phím chức năng Windows (Ctrl, Alt, Win, Shift, Esc, F1-F12).
- Nhận âm thanh hệ thống thời gian thực (WASAPI Loopback).
- Đồng bộ Clipboard hai chiều.
